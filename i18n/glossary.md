## 合规措辞（强制统一）

## 禁词（阿拉伯语）

| 禁用词 | 原因 | 替代表达 |
|---|---|---|
| دكتور / طبيب（医生）指代自己 | 暗示医疗资质 | منسق / ممرضة |
| نضمن / نكفل（保证） | 医疗无保证 | نساعد / ندعم |
| علاج / تشخيص（治疗/诊断）作为自己提供的服务 | 暗示行医 | تنسيق / استشارة |
| أفضل مستشفى（最好医院） | 绝对化用语 | مستشفيات رائدة（领先医院） |
| أرخص / أقل سعر（最便宜） | 价格误导 | أسعار شفافة（透明定价） |
